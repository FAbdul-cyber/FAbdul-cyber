### Azure Microsoft Defender for Endpoint

This project focuses on securing a Microsoft Azure environment through identity and access management, endpoint detection and response, and SOC-style security investigations.

**Project objectives:**

- Create Microsoft Entra ID employee accounts and implement least-privilege RBAC permissions
- Deploy and onboard a Windows Server endpoint to Microsoft Defender for Endpoint
- Simulate suspicious endpoint activity using PowerShell in a controlled environment
- Investigate security alerts through alert details and process-tree analysis
- Perform remote endpoint investigations using Microsoft Defender Live Response
- Investigate repeated failed authentication attempts using Azure Log Analytics and KQL
