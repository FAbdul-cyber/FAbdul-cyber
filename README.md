## 🔐 Cybersecurity Projects

### Azure Microsoft Defender for Endpoint

Completed a hands-on cybersecurity project within Microsoft Azure, covering identity and access management, network traffic analysis, endpoint protection, threat detection, incident investigation, and remediation.

**Project Highlights:**

- Configured Microsoft Entra ID user accounts and implemented resource group-level RBAC permissions to support least privilege.
- Investigated suspicious network traffic using Azure Log Analytics, KQL, and VirusTotal.
- Simulated brute-force authentication attempts and developed threshold-based detection queries.
- Onboarded and verified a Windows Server endpoint in Microsoft Defender for Endpoint.
- Conducted a controlled PowerShell attack simulation and analyzed the underlying attack techniques.
- Investigated security alerts, endpoint evidence, and process trees.
- Performed endpoint containment through device isolation.
- Executed remote file remediation and verified successful quarantine using Microsoft Defender Live Response.

**Key Technologies:** Microsoft Azure, Microsoft Entra ID, Microsoft Defender for Endpoint, Azure Log Analytics, KQL, PowerShell, and VirusTotal.
